---
description: Confere o GitHub e baixa o que o celular (ou outro lugar) mudou, sem perder nada que está aqui
---

Sincronize este computador com o GitHub agora. Isso já roda sozinho ao abrir
uma sessão; este comando serve para repetir no meio do trabalho.

1. Rode `node .claude/hooks/sincronizar.mjs` e leia o resultado.
2. Conte ao Renan, em português simples e em poucas linhas, o que aconteceu:
   baixou algo (e o quê), está tudo em dia, ou há algo que ele precise decidir.
3. O script **nunca** sobrescreve trabalho local e nunca força nada. Se ele
   avisar de mudanças sem commit ou de histórico divergente, **não tente
   resolver por conta própria**: explique o que há dos dois lados e proponha
   o caminho (por exemplo, rodar `/enviar` primeiro).
4. Se baixou commits, resuma o que mudou olhando as mensagens deles, para o
   Renan saber o que o celular fez.
